# 적재 조건표 (payload-conditioned residual 수집용)

공차 기준 (TruckMaker Vehicle Data Set → Body → Info):
- 공차 총질량 **M0 = 32000 kg**
- 공차 CoG x **x0 = 4.330 m**

계산식:
- `MASS  = M0 + payload`
- `COG_X = (M0*x0 + payload*x) / MASS`

⚠️ **TruckMaker Loads 표에 넣는 값 = 적재물(payload)** 이지 총질량이 아님.
Loads 표: 빨강 행에 `kg=payload`, `x=위치`, `y=0`, `z=2`. (Truck Loads 섹션, x는 1~5)

| Loads칸 payload | x [m] | MASS (총) | COG_X | collect.sh env |
|:---:|:---:|:---:|:---:|:---|
| (없음) | — | 32000 | 4.330 | `MASS=32000 COG_X=4.330` |
| 8000  | 2.0  | 40000 | 3.864 | `MASS=40000 COG_X=3.864` |
| 8000  | 4.33 | 40000 | 4.330 | `MASS=40000 COG_X=4.330` |
| 8000  | 5.0  | 40000 | 4.464 | `MASS=40000 COG_X=4.464` |
| 16000 | 2.0  | 48000 | 3.553 | `MASS=48000 COG_X=3.553` |
| 16000 | 4.33 | 48000 | 4.330 | `MASS=48000 COG_X=4.330` |
| 16000 | 5.0  | 48000 | 4.553 | `MASS=48000 COG_X=4.553` |
| 24000 | 2.0  | 56000 | 3.331 | `MASS=56000 COG_X=3.331` |
| 24000 | 4.33 | 56000 | 4.330 | `MASS=56000 COG_X=4.330` |
| 24000 | 5.0  | 56000 | 4.617 | `MASS=56000 COG_X=4.617` |

메모:
- `x=4.33` → CoG 불변(무게만 변함, 순수 무게효과 격리). `x=2.0/5.0` → CoG 이동.
- `x=6`은 적재함 밖(캐빈 침범) → x는 1~5만.
- 56톤(payload 24000)은 곡선서 이탈 가능 → 안 되면 무게 낮추거나 제외.
- 수집: 조건별로 Loads 설정 + 해당 env로 `collect.sh`, 같은 `OUT_NPZ`에 누적.

## 1차 추천 (무게만, CoG 고정 x=4.33)
`(없음)32000 → 8000@4.33 → 16000@4.33 → 24000@4.33` (COG_X 전부 4.330)
→ 무게 조건화 작동 확인 후 x=2.0/5.0 추가.
