# 논문 정리: 컨트리뷰션 · 방법 · 발견

적재 변화에 강건한 대형 트럭(TruckMaker 8×4)을 위한 **Frenet Kinematic + 학습 잔차(residual) MPC**.
Hockenheim 서킷, 적재 32~56 t. 이 문서는 논문/발표용 핵심 정리이다.

---

## 1. 컨트리뷰션 (4)

**① 대형 트럭에 kinematic + residual MPC 적용·검증**
- 적재가 32~56 t로 크게 변하는 8×4 트럭 (기존은 대부분 쿼드로터·승용차).
- Nominal 대비 **횡오차 −66~68%** (전 적재), 10 Hz 실시간.

**② 잔차의 종/횡 채널 분리**
- 횡방향(Δn, Δα): 신경망이 **78~84% 보정** (상태로 예측 가능 → 학습 적합).
- 종방향(Δs, Δv): **1~16%만** (기어변속 노이즈, 변속기 내부상태가 입력에 없어 예측 불가).
- → 횡은 residual 학습, 종은 물리/sys-id로 역할 분담.

**③ 적재-강건성: 무게 입력 없이 상태만으로 전 적재 일반화**
- MLP 입력에 무게를 **안 넣어도**(상태 6개) 단일 residual이 32~56 t 일반화.
- 상태(δ·α·D)가 **적재의 충분통계량** → 조건화(무게/CoG 입력) 불필요.
- 근거: 무게 ΔR²≈0 (선형/비선형/GradientBoosting 모두), CoG ΔR²≈0.0002, 고속(14 m/s)서도 0.

**④ residual 통합방식 규명 — zero-order(값만)가 원리적 (실차)**
- l4acados 기본 **first-order(값+미분)는 어떤 λ로도 발산**, **zero-order(값만)만 완주** + **1.76× 빠름**.
- 미분은 **정확히 식별되나**(model-free 여기측정 −0.51 ≈ 학습 −0.54) **주입 자체가 구조적 불안정**.
- → 데이터/DAgger로 못 고침. 값만 쓰는 zero-order가 유일한 안정해. **(가장 독창적)**

## 2. 방법 (핵심 수식)

- **예측모델(잔차 주입):**  ẋ = f(x,u) + B·Δ(x)
- **잔차 정의:**  Δ(xₖ) = x_{k+1}^실제 − f_d(xₖ,uₖ)   (실제 − nominal 예측)
- **MLP:**  Δ = W₃·tanh(W₂·tanh(W₁x+b₁)+b₂)+b₃,  입력 6D `[n,α,v,D,δ,κ]` → 출력 4D `[Δs,Δn,Δα,Δv]`, 은닉 64-64(tanh), ~5K 파라미터.
- **OCP(MPC가 매 스텝):**  min Σ‖x−x_ref‖²_Q + ‖u‖²_R  s.t.  x_{k+1}=f_d+Δ, 제약(n,δ,a_lat,…). N=20, SQP-RTI, acados+l4acados.
- **first vs zero-order(⭐):**  선형화 A = ∂f/∂x + **λ·∂Δ/∂x**. λ=1 발산 / λ=0(값만) 완주.
- **횡 동역학:** ṅ = v·sin(α+C₁δ), α̇ = v·C₂·δ − κ·ṡ. **질량은 종방향(v̇=Fx/m)에만** → 횡방향 적재효과가 잔차로 빠짐.

**Nominal 파라미터(고정):** m=30000(차체, 적재 무시), lf=2.25, lr=2.07, C1=lr/(lf+lr)=0.479, C2=0.5/(lf+lr)=0.116, Cm1=28739, Cm2=1415.7, Cr2=12.78, Cr0=3381.7, Cr3=11.0. 종방향 힘 Fx=(Cm1−Cm2·v)D − Cr2·v² − Cr0·tanh(Cr3·v). **적재가 바뀌어도 nominal은 안 바꿈** — residual이 담당.

**MPC 제약:** 조향 δ∈[−30°,30°](hard), 횡이탈 n∈[−1,1]m(soft), 횡가속 a_lat∈[−5,5](soft), 종가속 a_long∈[−10,10](soft), v∈[0,150], D∈[−1,1], 입력율 Ḋ·δ̇∈[−1,1].

## 4. 정직한 스코프 (심사 대비)

**"미분이 정확한데 왜 발산?"** — "미분값이 맞나"(여기실험, model-free, MPC 안 씀)와 "미분을 MPC에 넣으면 안정한가"(실차 λ-스윕)는 다른 질문. **정확한 값이어도 주입이 구조적으로 불안정** → 데이터로 못 고침.

**여기(excitation) 실험 = 미분 정확성의 model-free 증거.** 조향을 경로와 무관하게 랜덤으로 흔들어(δ 탈공선, VIF 37→6) 인과 미분을 직접 측정 → 12 m/s에서 −0.51, 학습값 −0.54와 일치.

**정확성은 on-manifold 한정** (figT5): seed 3개가 데이터 위에선 9% 일치, 밖에선 25~41% 붕괴. → residual은 검증영역 내에서만 신뢰.

**기전(discussion, 단일작동점 선형추정):** 미분 주입 시 조향→횡위치 **제어권한 26%로 붕괴**(figT7), 단 eig·조건수는 정상(LQR이 못 잡는 이유) → 과지령 → 분포이탈 → 발산.

**Load-bearing 증거:** ① 실차 λ-스윕(어떤 nonzero도 발산) ② 여기 인과측정 ③ off-manifold. 상쇄·권한붕괴는 기전 설명.

**조건화 불필요는 잉여성 "발견"이지, "조건화가 성능을 올린다"가 아님.** 무게를 넣어도 이득 0(정보이론적). 프레이밍은 "payload-robust"(무게 없이 강건).
