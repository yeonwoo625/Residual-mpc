연구 배경
Motivation
왜 kinematic + residual 인가
  • MPC 예측모델: kinematic(단순·저속 안정) vs dynamic(정확하나 타이어·관성 파라미터 부담, 저속 수치 불안정)
  • 대형 트럭은 공차 32t → 만차 56t, 무게·무게중심이 크게 변해 kinematic의 구조적 오차가 커짐
  • 목표: kinematic의 단순함을 유지하며, 모델이 놓친 오차를 학습 잔차로 보정

방법
Residual MPC
예측모델 = 명목 + 학습 잔차
  • 예측 상태 = 명목 kinematic 자전거 모델 + 학습 잔차(MLP). 잔차를 행렬 B로 예측모델에 주입: ẋ = f(x,u) + B·Δ
  • 잔차 = 실제 다음 상태 − 명목 예측 (지도학습 회귀). acados + l4acados로 OCP 구성.

기여 ①
성능
명목 대비 횡오차 −66~68% (파라미터 동정 없이)
  • 32/48/56t 전 적재에서 명목 kinematic MPC 대비 횡오차 −66~68%
  • dynamic 파라미터(Cf·Cr·Iz) 동정 없이 달성 — 물리 부담 회피
  • kinematic은 저속 특이점 없음 → 대형 트럭 실시간 MPC에 유리 (정성적 이점)
물리로 설명되는 부분은 명목이, 놓친 부분은 학습 잔차가 보정.

기여 ②
종/횡 하이브리드
횡은 residual, 종은 물리/sysid (R² 근거)
  • 횡(Δn·Δα): 상태 선형 R²=0.98 + 신경망 84% 저감 → residual로 처리
  • 종(Δs·Δv): 선형 R²<0.05 + 비선형 MLP도 1~16% → 물리/sysid로 처리
  • 선형 R² + 비선형 저감 두 독립 증거로 하이브리드 설계 정당화
종잔차는 상태로 예측 불가(노이즈/기하) — residual이 원리적으로 못 잡음.

기여 ③
적재-강건
상태가 적재를 담아 조건화 불필요 → 일반화
  • 상태(v·D·δ·α)가 적재 효과를 충분히 반영 → 무게·CoG 입력이 정확도에 추가 이득 없음
  • 단일 적재-blind residual이 무게 32~56t·CoG 1.5~5.5·속도 12~14m/s (외삽·미학습 포함)서 82~88% 일관 보정
  • 무게(보간·외삽·포화)·CoG·고속 다각도로 확립
적재별 모델·적재 센싱 없이 하나의 상태 기반 모델로 일반화.

기여 ④-1
first-order 발산
어떤 nonzero Jacobian도 발산 → 구조적
  • l4acados 기본 first-order(잔차 Jacobian 주입)가 실차 급코너서 조향 진동·발산
  • zero-order(값만)만 안정 완주
  • λ-스윕: 크기·부호 무관 전부 발산 → 값의 bias가 아니라 미분 주입 구조가 원인 (분리·입증)

기여 ④-2
메커니즘 + 속도
조향 오조율 → 과조향 진동 / zero-order가 더 빠름
메커니즘: 잔차 미분이 조향감도를 오조율 → 과조향(저크 2.4배) → 오버슛 진동 (해석; 실차 증폭 물리는 향후 과제).  ·  속도: zero-order는 신경망 Jacobian 생략 → 1.76배 빠름, 본 환경(10Hz) 실시간 충족.
