# Ablation: 무게 입력(조건화) vs 무게 무시 — 무게 채널의 기여

feedforward 잔차 MPC에서 **MLP 입력에 무게(+CoG)를 넣는지 여부**만 다른 두 모델 비교.
차이 = mass 채널만 (split seed=42 고정으로 cond/nomass가 같은 train/val 분할 사용; init RNG는 아키텍처 차이라 3시드로 정량화).

## 파일
`abl_{cond,nomass}_{32,56}[_sN].npy` — 각 `(N,6)` = `[s,n,alpha,v,D,delta]`
- `cond`   = 무게 입력 O (8차원 모델, `MASS`/`COG_X` 조건화)
- `nomass` = 무게 입력 X (6차원 모델)
- seed0 = suffix 없음, seed1/2 = `_s1`/`_s2`
- 48t는 seed0만 (중점 참고). 32t·56t는 seed0/1/2.
- `hockenheim_nomass.npz` = 무조건화 학습 데이터 (mass 열 제거)
- 모델: `mpc/residual_model_{cond,nomass}_s{0,1,2}.pt`

## 결과 (급코너 |n| RMS, 3시드 paired)
| 무게 | 조건화 | 무조건화 | 차이(무조건화−조건화) |
|---:|---:|---:|---:|
| 32t | 0.281±0.028 | 0.332±0.014 | +0.051 |
| 56t | 0.368±0.021 | 0.415±0.050 | +0.047 |

**6페어 (무조건화−조건화)**: +0.030,+0.095,+0.029,+0.073,−0.011,+0.079
- 평균차이 **+0.049 m (~13%)**, SE 0.016
- paired t-test p=0.030, 부호검정 5/6 p=0.109
- → **조건화가 급코너서 ~13% 개선(시사적, modest); n=6라 유의성 경계적. 적재 의존성은 이 데이터로 확인 불가** (1시드의 "적재 따라 증가"는 시드 노이즈였음).

그림: `../figures/fig9_conditioning_ablation.png` (개별 시드 점 표시).

## 재분석 (2026-09-03) — 예측 오차와 플라시보를 넣으면 결론이 뒤집힌다

기존 결론은 **"조건화가 급코너서 ~13% 개선(시사적)"** 이었다. 폐루프 추종 오차만
봤기 때문이다. 두 가지를 추가하면 그 개선이 **무게 정보 때문이 아님**이 드러난다.

### ① 예측 오차 — 무게를 알려줘도 안 줄어든다

학습에 쓰지 않은 검증 분할(1,617 샘플, random seed=42)에서 1스텝 예측 오차.
적재 32 / 40 / 48 / 56 t 전부.

| 적재 | 보정 없음 | 무게 X | 무게 O | **조건화 이득** |
|---:|---:|---:|---:|---:|
| 32t | 0.0350 | 0.0042 | 0.0041 | **3.0%** |
| 40t | 0.0367 | 0.0053 | 0.0051 | **2.5%** |
| 48t | 0.0438 | 0.0080 | 0.0080 | **0.1%** |
| 56t | 0.0470 | 0.0107 | 0.0107 | **0.1%** |

(횡 Δn, m. 헤딩 Δα 는 +7.4 / +4.2 / **−7.0** / **−3.3** % 로 부호가 갈린다.)

**잔차 보정 자체는 예측 오차를 8배 줄이지만, 무게를 입력에 넣는 것이 더 보태는
양은 0~3% 로 시드 편차 수준이다.** 적재가 클수록 오히려 0 에 수렴한다.

### ② 플라시보 — 섞은 무게가 이득의 절반 이상을 재현한다

`abl_shufmass_48_s{0,1,2}` = 무게 라벨을 무작위로 섞어 학습. 입력은 8차원으로
같지만 **무게 정보는 없다.**

| 48 t | 급코너 \|n\| RMS | 급코너 α RMS |
|---|---:|---:|
| 무게 없음 (6차원) | 0.425±0.029 | 2.278±0.277 |
| 진짜 무게 (8차원) | 0.340±0.028 | 2.035±0.022 |
| **섞은 무게 (플라시보)** | **0.382±0.021** | **2.006±0.008** |

**섞은 무게가 '조건화 이득'의 51%(횡), 112%(헤딩)를 재현한다.**
헤딩은 플라시보가 진짜 무게보다 오히려 좋다.

### 결론

폐루프에서 관측된 조건화 이득은 **무게 정보가 아니라 입력 차원 증가·초기값·
학습 노이즈**에 기인한다. 무게를 MLP 입력에 넣을 근거가 없다.

이는 `results/payload_observability.py` 와 일치한다 — 무게는 상태로부터 R²=0.79
로 복원 가능하며(주로 D), 입력이 주어진 뒤 추가 설명력은 0.34% 다. **무게는 이미
상태에 인코딩돼 있다.**
