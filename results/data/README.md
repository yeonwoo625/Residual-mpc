# 추가 검증 데이터 (조건화 규명 · first-order 진단)

## CoG 변동 실험 (기여 ③ — 조건화 불필요 규명)
- `cog_front48.npz`, `cog_rear48.npz` — 48t 고정, CoG x=1.5(전방)·5.5(후방), Hockenheim 12 m/s, 명목 MPC.
- 중앙(4.33)은 `hockenheim_mass.npz`의 48t 서브셋 재사용.
- 결과: CoG가 횡잔차에 영향(+15%)을 주지만 상태로 완전히 설명됨(CoG ΔR²=0.0002) → CoG 조건화도 불필요.

## 고속 실험 (기여 ③ — 비선형 영역서도 조건화 불필요)
- `hs14_32.npz`, `hs14_56.npz` — 32t·56t, Hockenheim **14 m/s**(비선형 타이어 근처), 명목 MPC.
- 결과: 고속서 잔차는 커지나(0.035→0.066) 무게와 무관(32t=56t), 무게 ΔR²=0.0000 → 고속서도 조건화 무용.
