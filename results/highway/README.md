# 미학습 트랙 일반화 (USA Highway No.1), 2026-09-01

## 왜 했나

일반화 축이 '적재' 하나뿐이었다. **트랙 축**을 추가했다.

## 설정

| 항목 | 값 |
|---|---|
| 학습 | **Hockenheim** (`mpc/residual_model_nomass_s0.pt`) — **재학습 없음** |
| 시험 | **USA Highway No.1** (`USA_HighwayNo1_3DMapping.rd5`, TestRun `highway_no1`) |
| 경로 | `highway_waypoints.npy` — IPGDriver 주행을 `scripts/record_path.py` 로 녹화 (461점, 931 m) |

**곡률 검증:** 이 경로의 κ 는 학습 데이터 분포(1~99%) 밖 비율이 **0.0%** 다.
외삽이 아니라 순수한 경로 일반화다. 최소 회전반경 Hockenheim 37.8 m vs Highway 91.8 m.

## 왜 결정적인가 — 성능이 아니라 가능/불가능이 갈렸다

이 도로는 **차선 3.5 m, 트럭 2.49 m** 라 좌우 여유가 각 **0.5 m** 뿐이다.

```
nominal  최대 0.835 m  ->  여유의 165%  ->  바퀴가 도로 밖
residual 최대 0.213 m  ->  여유의  42%  ->  완주
```

TruckMaker 로그:
```
ERROR      Vehicle leaves road at about x=-5.5682, y=223.921 TireNo=1
SIM_ABORT  highway_no1  70.425s  624.986m
```

**nominal 은 이 도로를 주행할 수 없고 residual 은 할 수 있다.** Hockenheim(서킷,
폭이 넉넉)에서는 둘 다 완주했으므로 드러나지 않던 차이다.

## 의미

잔차가 특정 경로의 곡률 프로파일을 암기한 것이 아니라 **차량 자체의 모델 오차를
학습**했음을 보여준다. 곡률 분포가 다른(반경 2.4배) 다른 종류의 도로(서킷 → 측정
고속도로)에서 재학습 없이 그대로 작동했다.

## 헤딩오차(α = yaw error) — 2026-09-02 추가

횡오차만 보고하면 "유리한 지표만 골랐다"는 반박을 받으므로 α 도 싣는다.

| | RMS α | 최대 α |
|---|---|---|
| nominal | 0.90° | 1.89° |
| residual | 0.87° | 1.85° |
| | −4% | −2% |

**차이가 거의 없다.** 이 트랙에서 잔차의 이득은 사실상 전부 횡방향이다.

> 주의: nominal 은 624 m 에서 이탈해 residual(925 m)과 **주행 구간이 다르다.**
> 위 α 는 각자 주행한 구간에서 잰 값이라 엄밀한 짝비교가 아니다. 횡오차 비교도
> 같은 한계를 갖지만, nominal 이 더 짧은(=쉬운 초반) 구간만 달리고도 더 나빴으므로
> 결론 방향에는 영향이 없다.

## 이탈 검증 및 여유 계산 정정 (2026-09-03)

### 재현 확인

nominal 을 같은 설정으로 다시 돌려 CarMaker 가 스스로 중단하는 것을 확인했다.

```
ERROR      Vehicle leaves road at about x=-5.56941, y=223.924  TireNo=1
SIM_ABORT  highway_no1   71.054s   624.993m
```

기존 주행(624 m)과 **거의 같은 지점**이다. 이탈은 실재하며 재현된다.

### 여유 0.5 m 계산은 근거가 틀렸다

기존 서술은 *차선 3.5 m − 트럭 2.49 m → 좌우 여유 0.5 m* 였다. 그러나 `.rd5` 를
읽어 보면 이 도로는 차선 하나가 아니다.

```
LaneL: 0.095 + 3.50 + (0.75~4.50) + 1.0   -> 편도 최대 8.1 m
LaneR: 0.095 + 3.50 + (0.21~1.99) + 1.0   -> 편도 최대 5.6 m
```

갓길 폭이 **s 에 따라 변한다**(0.21~4.50 m). 즉 여유는 고정 0.5 m 가 아니다.

실제 데이터도 그 점을 보여준다.

| | |
|---|---|
| nominal 랩 전체 최대 \|n\| | **0.835 m** (s = 524 m) — **여기서는 이탈하지 않았다** |
| 이탈 지점 s = 625 m 의 \|n\| | **약 0.46 m** |
| 같은 지점 residual \|n\| | **0.10 m** |

**최대 오차 지점이 아니라 도로가 좁은 지점에서 이탈했다.** 0.835 m 를 견딘 구간이
있으므로 "여유 0.5 m 를 1.65배 초과" 라는 서술은 성립하지 않는다.

### 올바른 서술

> 실도로 폭(차선 3.5 m + 가변 갓길)에서 nominal MPC 는 s = 625 m 지점에서
> 우측 타이어가 도로를 벗어나 시뮬레이션이 중단됐다(재현 확인). 같은 지점에서
> residual MPC 의 횡편차는 0.10 m 로, 전 구간을 완주했다. 도로 여유폭이 구간마다
> 다르므로 단일 임계값으로 환산하지 않는다.

**결론(완주 여부가 갈린다)은 유지되며, 정량화 방식만 바로잡았다.**

### 고속 실험에 주는 함의

이 도로는 **좁은 구간이 있어 고속 주행 실험에 적합하지 않다.** residual 의 최대
\|n\| 이 v=12 에서 0.213 m 인데, 횡오차가 대략 v^2 에 비례하므로 v=20 이면
0.6 m 수준이 되어 양쪽 다 이탈할 가능성이 높다.

## 좌측 1 m 이동 경로 (L1) 주행 — 2026-09-03~04

원래 경로는 우측 여유가 좁아 nominal 이 s=625 m 에서 이탈했다(위 절 참조).
`scripts/shift_path.py` 로 경로를 좌측 1 m 평행이동해 여유를 확보하고 다시 주행했다.

| 파일 | 조건 |
|---|---|
| `hw_{nom,res}_L1.npy` | v=12, 정지 출발 |
| `hw_{nom,res}_v20.npy` | v=20, 정지 출발 — 925 m 대부분이 가속 구간(v≥19 가 4%) |
| `hw_{nom,res}_v20i.npy` | **v=20, 초기속도 72 km/h** — 주행의 84% 가 v≥15. **고속 검증의 정본** |
| `highway_waypoints_L1.npy` | 이동한 기준 경로 (932 m, 최소반경 90.2 m) |

전부 48 t, `Q_n=1e-4`, 잔차 scale 0.3, 6차원 모델(재학습 없음), **양쪽 10 Hz**.
솔버 수정(SQP_ITER=10) 이후라 제어율이 맞는 비교다.

**고속에서 헤딩오차 개선이 가장 크다(77%).** 속도가 높을수록 kinematic 의 슬립 0
가정이 깨지고 그 오차가 헤딩에 나타나는데, 잔차가 이를 보정한다.

### 주의

- **초기속도는 TestRun 의 `DrivMan.Init.Velocity` 이고 단위가 km/h 다.**
  `72` = 20 m/s. MPC 의 `TARGET_SPEED` 는 m/s 이므로 한 실험에 두 단위가 섞인다.
- v=20(초기속도)에서 residual 이 nominal 보다 **빠르다**(평균 17.71 vs 16.66 m/s).
  "느려서 정확한 것"이라는 반박은 성립하지 않으나, 속도가 다르다는 점은 밝혀야 한다.
- 급코너 기준은 곡률 상위 20%(\|κ\| ≥ 0.0081, R ≤ 123 m). 이 도로는 Hockenheim
  기준 0.02 를 한 번도 넘지 않는다.
