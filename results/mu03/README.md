# 저마찰 노면 실험 (μ = 0.3), 2026-08-31

## 왜 했나

마른 노면에서는 nominal 의 비용 가중치 튜닝만으로 잔차의 이득을 거의 전부
대체할 수 있었다(`results/b1/`). 그렇다면 **잔차가 실제로 필요한 영역이 있는가?**

kinematic 모델의 "타이어 슬립 = 0" 가정이 크게 깨지는 조건에서 검증했다.

## 설정

| 항목 | 값 |
|---|---|
| 도로 | `DEU_Hockenheim_mu05.rd5` — `Link.0.Friction = 0.3` (**파일명은 mu05 지만 내용은 0.3**) |
| TestRun | `hockenheim_mu05` (TMROS2/Data/TestRun) |
| 적재 | 48 t (Load 16000) |
| 가중치 | Q_n = 1e-4 (기본) |
| 잔차 모델 | `model_mu03.pt` — 이 노면에서 재수집한 `dataset_mu03.npz`(4,978 샘플)로 학습 |

⚠️ **마른 노면 데이터와 합치지 않았다.** 마찰이 MLP 입력에 없으므로 두 노면을
합치면 같은 입력에 다른 정답이 대응해 학습이 불가능해진다(종방향 기어 문제와 동일 구조).

**v=9 에서 잔차가 급코너 오차를 33.8% 감소시킨다 (0.699 → 0.462).**

## 핵심 발견 — 작동 조건이 있다

**잔차 보정은 타이어에 여유가 있을 때만 유효하다.**

- 마찰 사용률 **73%** → 34% 개선, 완주
- 마찰 사용률 **90%** → 조향 ±30° 포화, **4회 시도 전부 이탈**

재학습·잔차세기 축소(0.3→0.1)·조향률 벌점 10배 — 어느 것도 v=10 을 구하지 못했다.
데이터나 튜닝 문제가 아니라 구조적 한계다.

### 기전

잔차는 "예측보다 더 밀리므로 더 조향하라"는 보정을 준다. 그런데 마찰 한계에서는
추가 조향이 횡력으로 변환되지 않는다 — 실측한 조향 실효이득(실제 요레이트 /
kinematic 모델 예측)이 v=9 의 0.65 에서 v=10 의 0.37 로 절반이 된다. 그 결과

```
잔차 "더 밀린다" -> MPC 더 조향 -> 힘 안 늘어남 -> 더 밀림 -> ... -> ±30° 포화 -> 스핀
```

nominal 은 밀리는 것을 모르므로 덜 꺾어 살아남지만 최대 6 m 밀린다
(정확도를 포기하고 안정성을 얻은 셈).

**잔차가 정확할수록 MPC 를 더 세게 밀어붙이며, 밀어붙일 여지가 없으면 발산한다.**
이는 `results/b1/` 의 다른 실패(고게인 + 잔차 → 발산)와 같은 원인이다.

## μ=0.5 는 왜 효과가 없었나

처음에 μ=0.5 로 시도했으나 마른 노면과 결과가 같았다(0.837 vs 0.854).
이 트럭은 v=10, R=37.7 m 코너에서 **마찰을 0.27 밖에 쓰지 않는다.** μ=0.5 여도
사용률이 54% 라 타이어가 선형 영역에 머문다. 거동을 바꾸려면 μ=0.3(90%)이 필요했다.

## 정정 (2026-09-02) — 기전은 조향이 아니라 **제동**이었다

위 "기전" 절의 서술(*잔차 → 더 조향 → 힘 안 늘어남 → 더 밀림 → 포화 → 스핀*)은
**틀렸다.** 속도를 맞춘 주행으로 확인했다.

### 무엇을 했나

기존 비교는 **속도가 달랐다.** 같은 목표 10 m/s 에서 실제 속도가
nominal 9.895, residual 10.08 (+1.9%) 로, residual 이 항상 마찰 한계에 먼저
도달한다. "속도가 달라서 실패한 것 아니냐"에 답하기 위해 residual 목표를
9.42 로 낮춰(실제 9.5) nominal 의 9.9 보다 **느린** 조건에서 다시 돌렸다.

`mu03_v95_res.npy` — μ=0.3, 목표 9.42, 48 t, SQP_ITER 수정 후(solve 24 ms).

### 결과: 더 느린데도 실패했다 — 속도 가설 반증

s ≈ 1250 에서 스핀 후 트랙을 가로질러 정지(s=1280, α=-19.3°, v=0).
max |n| 은 2.87 로 기존 이탈(7.93)보다 **작다. 도로 밖으로 밀려난 것이 아니다.**

같은 코너에서 두 제어기가 정반대로 움직인다.

| s | nominal (실제 9.9) D / α | residual (실제 9.5) D / α |
|---|---|---|
| 1250 | **+1.00** / 7.6° | **−0.44** / 3.8° |
| 1255 | **+1.00** / 8.0° | **−0.84** / 5.6° |
| 1275 | +1.00 / 1.0° | −0.60 / **−19.2°** |

- **nominal: 풀 스로틀.** 6 m 밀리지만 차체는 앞을 보고(α 최대 8°) 빠져나온다
- **residual: 풀 브레이크.** 9.4 → 0 m/s, α 가 +9.5° → −19.3° 로 넘어가 스핀

### 올바른 기전

μ=0.3 에서 타이어 그립은 횡·종이 **하나의 예산(마찰원)** 이다. 코너에서 이미
횡으로 다 쓰고 있는데 거기서 제동하면 예산을 넘겨 뒤가 돌아간다.

잔차는 밀리는 것을 안다. 조향은 이미 −30° 락이므로 남은 수단이 감속뿐이고,
**그 제동이 스핀을 만든다.** nominal 은 밀리는 것을 모르고 s 가 뒤처지니 오히려
가속한다 — 판단 자체는 틀렸으나 마찰원을 건드리지 않아 살아남는다.

**"잔차가 정확할수록 세게 밀어붙인다"는 결론은 유지되나, 밀어붙이는 채널은
조향이 아니라 종방향이다.**

### 남은 한계

- nominal 을 같은 9.5 로 돌린 짝이 없다(9.9 에서 완주했으므로 9.5 에서도
  완주할 것이라는 추론에 의존). 저마찰 실험을 여기서 중단했다
- QP 로그의 `ACADOS_MINSTEP` 은 v=0 이 된 **뒤에** 발생한다. 운동학 모델에서
  v=0 이면 ds/dt=0 이라 목표 s 에 도달할 수 없어 문제가 풀리지 않는 것으로,
  정지의 결과이지 원인이 아니다
